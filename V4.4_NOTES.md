# Talos v4.4 OSINT initial integration
- Keeps Render + Neon, existing splash image and trading modules.
- Adds a small allowlisted RSS collector (SEC, Federal Reserve, CISA, BBC World/Business) running every 30 minutes, delayed 45 seconds after startup.
- PostgreSQL deduplication by source + URL and a read-only ranked feed API at `/api/v1/osint/feed`.
- Focused dashboard: paper equity, active jobs, DB status, news feed, worker status.
- Feed ranking is keyword-based; not ML confidence, predictive signal, or verified market impact.
- Source fetch failures log warnings and never create fake articles. Some providers may reject Render IPs.
- Other OSINT connectors (GDELT, GitHub, exchange announcements, on-chain) and signal linkage are NOT implemented in this increment.
- Existing tables are created with SQLAlchemy create_all. Production migration and complete frontend build are NOT verified.
- Feed refresh is 30 minutes; dashboard reads it every 30 seconds. No promise of instant breaking-news detection.
